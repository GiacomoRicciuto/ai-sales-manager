# atlante — Meta-framework orchestratore

L'atlante è la **meta-skill**: non è un libro singolo, è una mappa orchestratrice che guida la scelta della metodologia giusta a partire dal contesto della trattativa. Inquadrato come **metodo italiano di vendita high-ticket**, incrocia il corpus delle altre 9 famiglie con il filtro culturale del mercato italiano (vendita IT ≠ vendita USA, sintomo vs causa, dibattito non scontro, mai concordare con l'obiezione).

## Quando attivarla
- **Triage iniziale di una call**: scoring stadio funnel, cultura buyer, locus di controllo, tipo obiezione, stake.
- **Scelta del libro giusto** prima di rispondere: invocazione dinamica di massimo 3 skill-libro per query.
- **Post-mortem** di trattative complesse: analisi 100% italiana, contesto culturale, gestione obiezioni.
- **Coaching del rep** che non sa quale framework applicare a quale scenario.
